# Control de proyecto

Esta carpeta mantiene el seguimiento documental del proyecto: riesgos, dependencias, preguntas abiertas y tareas tecnicas. Sirve para que las dudas y decisiones pendientes no se pierdan en conversaciones informales.

## Documentos

| Documento | Proposito | Estado |
|-----------|-----------|--------|
| [riesgos.md](./riesgos.md) | Riesgos documentales, impacto, mitigacion y KPIs | Definido |
| [dependencias.md](./dependencias.md) | Dependencias internas y externas que afectan la documentacion | Definido |
| [preguntas-abiertas.md](./preguntas-abiertas.md) | Dudas que requieren decision o validacion | Definido |
| [backlog-tecnico.md](./backlog-tecnico.md) | Tareas tecnicas y documentales pendientes de mejora | Definido |
| [tablero-trello.md](./tablero-trello.md) | Propuesta de tablero Trello para gestionar el trabajo documental | Definido |

## Como se usa

1. Registrar riesgos que puedan afectar claridad, trazabilidad o seguridad.
2. Registrar dependencias que bloqueen avance documental.
3. Convertir dudas importantes en preguntas abiertas.
4. Llevar tareas concretas al backlog tecnico.
5. Gestionar el avance visible en el tablero Trello documental.

## Regla

Esta carpeta debe ayudar a decidir. Si un riesgo, pregunta o tarea no tiene accion posible, debe reescribirse o cerrarse.
