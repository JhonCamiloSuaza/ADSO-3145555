# Glosario

Este glosario define terminos base para que el equipo use el mismo lenguaje en todos los documentos.

| Termino | Definicion | Contexto |
|---------|------------|----------|
| SENA | Servicio Nacional de Aprendizaje. Institucion sobre la cual se orienta el proyecto. | Institucional |
| Regional | Division territorial usada para organizar centros de formacion. | Estructura institucional |
| Centro de formacion | Sede o unidad donde se desarrollan procesos formativos. | Estructura institucional |
| Ubicacion especifica | Lugar fisico asociado a un centro, ambiente o actividad. | Infraestructura |
| Ambiente | Espacio de formacion usado para clases, practicas o actividades academicas. | Infraestructura |
| Inventario | Conjunto de recursos disponibles en ambientes o espacios de formacion. | Infraestructura |
| Parametro | Configuracion reutilizable que controla opciones del sistema. | Parametrizacion |
| Catalogo base | Lista controlada de valores usados por varios modulos. | Parametrizacion |
| Programa de formacion | Estructura academica que define una oferta formativa. | Programas |
| Linea tecnologica | Clasificacion academica asociada al programa de formacion. | Programas |
| Red de conocimiento | Agrupacion tematica o academica relacionada con programas. | Programas |
| Diseno curricular | Definicion academica de competencias, resultados y estructura de un programa. | Programas |
| Competencia | Capacidad que debe desarrollar el aprendiz dentro del programa. | Programas |
| RAP | Resultado de Aprendizaje. Resultado esperado dentro de una competencia. | Programas |
| Ficha | Grupo o cohorte de aprendices asociada a un programa de formacion. | Oferta |
| Proyecto formativo | Proyecto usado como eje de aprendizaje y seguimiento academico. | Oferta y seguimiento |
| Entregable | Producto o evidencia asociada a un proyecto formativo. | Oferta |
| Aprendiz | Persona en proceso de formacion. | Actores |
| Instructor | Persona que orienta actividades formativas. | Actores |
| Directivo | Actor con responsabilidad de coordinacion, revision o toma de decisiones. | Actores |
| Horario | Asignacion de tiempo, ambiente, instructor, ficha o actividad. | Horarios |
| Incidencia | Situacion que afecta un horario, ambiente, actor o actividad programada. | Horarios |
| Observacion | Registro descriptivo asociado a una actividad, horario o seguimiento. | Horarios |
| KPI | Indicador usado para medir estado, calidad o avance. | Seguimiento |
| Auditoria | Registro de acciones relevantes para trazabilidad y revision. | Gobernanza |
| Microservicio propuesto | Limite tecnico documentado, aun sin implementacion real. | Arquitectura |
| Monolito modular | Sistema organizado por modulos internos claros, sin separar necesariamente despliegues. | Arquitectura |
| Trazabilidad | Capacidad de relacionar requisito, modulo, documento, servicio y decision. | Gobernanza |
