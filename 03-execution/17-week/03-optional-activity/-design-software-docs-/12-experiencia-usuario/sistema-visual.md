# Sistema visual

Este documento define reglas visuales iniciales para futuras pantallas.

## Principios

- Interfaz clara y sobria.
- Navegacion por modulos.
- Tablas legibles para datos academicos.
- Estados visibles para seguimiento, incidencias y aprobaciones.
- Evitar elementos decorativos que dificulten lectura.

## Componentes esperados

| Componente | Uso |
|------------|-----|
| Tabla | Listar fichas, ambientes, actores, horarios y eventos |
| Filtro | Buscar por regional, centro, ficha o estado |
| Formulario | Crear o editar datos controlados |
| Indicador | Mostrar KPIs o alertas |
| Calendario | Visualizar horarios y eventos |
| Modal | Confirmar acciones importantes |

## Regla

El diseno debe ayudar a operar informacion, no a mostrar una pagina decorativa.
