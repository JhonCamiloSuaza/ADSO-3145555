# Wireframes

Este documento define pantallas base que el equipo puede disenar despues. No son disenos finales.

## Pantallas principales

| Pantalla | Modulo | Objetivo |
|----------|--------|----------|
| Inicio / tablero | Transversal | Mostrar accesos principales y estado general |
| Gestion de estructura institucional | M02 | Administrar regionales, centros y ubicaciones |
| Catalogos y parametros | M04 | Mantener valores base |
| Ambientes e inventario | M03 | Consultar disponibilidad de ambientes |
| Programas de formacion | M05 | Gestionar programas, competencias y RAP |
| Fichas y proyectos | M06 | Administrar oferta y proyectos formativos |
| Actores | M07 | Consultar instructores, aprendices y directivos |
| Horarios | M08 | Asignar y revisar horarios |
| Seguimiento | M09 | Ver KPIs, alertas y notificaciones |
| Coordinacion y eventos | M10 | Programar eventos academicos |

## Regla

Cada wireframe debe relacionarse con un modulo y una historia de usuario.
