# Mapa de navegacion

Este mapa propone como podria organizarse la navegacion futura del sistema.

## Navegacion principal

1. Inicio.
2. Seguridad y acceso.
3. Estructura institucional.
4. Parametrizacion.
5. Infraestructura.
6. Programas de formacion.
7. Oferta y programas.
8. Actores.
9. Horarios.
10. Proyectos formativos.
11. Coordinacion y eventos.
12. Reportes y documentos.

## Regla

El orden de navegacion debe parecerse al orden funcional del dominio para que el usuario entienda la secuencia del proceso.
