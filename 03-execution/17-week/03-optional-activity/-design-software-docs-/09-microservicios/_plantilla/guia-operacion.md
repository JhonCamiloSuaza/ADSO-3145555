# Guia de operacion del servicio

Este archivo describe como se entenderia la operacion del servicio. No incluir credenciales ni configuraciones reales.

## Aspectos a documentar

- Responsabilidad operativa.
- Datos que deben monitorearse.
- Errores esperados.
- Dependencias criticas.
- Acciones ante incidentes.

## Checklist

- [ ] Tiene responsable conceptual.
- [ ] Tiene dependencias documentadas.
- [ ] Tiene eventos o APIs relacionados.
- [ ] No contiene secretos.

## Regla

La operacion real se documenta solo cuando el servicio exista.
