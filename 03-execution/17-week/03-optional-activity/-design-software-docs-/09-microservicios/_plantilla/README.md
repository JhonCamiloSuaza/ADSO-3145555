# Plantilla de servicio

Esta carpeta se copia solo cuando un servicio este aprobado para documentarse en `09-microservicios/servicios`.

## Informacion minima

| Campo | Que escribir |
|-------|--------------|
| Nombre del servicio | Nombre en kebab-case |
| Responsabilidad | Que hace y que no hace |
| Modulos relacionados | Modulos funcionales que cubre |
| Datos principales | Datos sobre los que tiene responsabilidad |
| Dependencias | Servicios o modulos que consulta |
| Eventos | Eventos que publica o consume |

## Regla

No crear servicios ficticios. Si el servicio no esta aprobado, debe permanecer solo en `catalogo-servicios.md`.
