# Calidad documental

Esta carpeta define como revisar que la documentacion sea clara, trazable y util. La calidad aqui no se limita a pruebas de software; tambien incluye nombres, estructura, enlaces, criterios y ausencia de informacion sensible.

| [revision-codigo.md](./revision-codigo.md) | Revision tecnica de documentos, contratos, diagramas y decisiones | Definido |

## Criterios de calidad

- El documento tiene objetivo claro.
- El nombre del archivo se entiende.
- La carpeta donde vive tiene sentido.
- El README de la seccion lo enlaza.
- No duplica una fuente canonica.
- No publica credenciales ni datos sensibles.

## Regla

Una revision documental debe dejar el repositorio mas facil de leer, no mas burocratico.
