# Revision tecnica y documental

Aunque este repositorio no contiene codigo de producto, si necesita revision tecnica de documentos, contratos, diagramas y decisiones.

## Que revisar

| Elemento | Revision |
|----------|----------|
| Documento nuevo | Proposito, ubicacion, enlaces y trazabilidad |
| Requisito | Claridad, modulo asociado y criterio de aceptacion |
| API | Recurso, requisito relacionado y seguridad |
| Microservicio propuesto | Limite claro, dependencias y datos |
| ADR | Contexto, decision y consecuencia |
| Diagrama | Fuente editable y relacion con documento |

## Checklist

- [ ] El cambio se entiende sin explicacion externa.
- [ ] No duplica una fuente canonica.
- [ ] No contiene datos sensibles.
- [ ] Actualiza README de carpeta.
- [ ] Actualiza matriz de trazabilidad si aplica.

## Regla

La revision busca mejorar claridad, no crear burocracia.
