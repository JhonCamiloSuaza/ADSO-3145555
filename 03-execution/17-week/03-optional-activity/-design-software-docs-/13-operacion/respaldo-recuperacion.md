# Respaldo y recuperacion

Este documento define criterios conceptuales para proteger la documentacion y, en el futuro, la informacion del sistema.

## Para este repositorio

- Conservar historial de cambios.
- No eliminar documentos importantes sin registrar reemplazo.
- Usar `99-archivo` para documentos deprecados.
- Mantener README actualizados para recuperar contexto rapido.

## Para el sistema futuro

- Definir respaldos de datos cuando exista base de datos real.
- Documentar responsables conceptuales de datos.
- Probar recuperacion antes de declarar estable una estrategia.

## Regla

No se documentan rutas, servidores, claves ni configuraciones reales en esta etapa.
