# Gestion de incidentes

Este documento define como registrar incidentes funcionales o documentales.

## Tipos de incidente

| Tipo | Ejemplo | Donde se relaciona |
|------|---------|--------------------|
| Documental | Enlace roto o documento duplicado | Gobernanza |
| Dominio | Regla contradictoria entre modulos | Dominio |
| Horario | Conflicto de ambiente o instructor | M08 |
| Seguimiento | KPI inconsistente | M09 |
| Seguridad | Informacion sensible publicada | Gobernanza |

## Registro minimo

- Fecha.
- Modulo afectado.
- Descripcion.
- Impacto.
- Accion tomada.
- Documento relacionado.

## Regla

Un incidente no debe quedarse como conversacion informal; debe registrarse donde corresponda.
