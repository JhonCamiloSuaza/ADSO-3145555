# Configuracion local

Este repositorio se trabaja como documentacion Markdown. No requiere levantar servidores ni instalar dependencias para editar los archivos.

## Recomendacion de trabajo

1. Abrir la carpeta del repositorio en VS Code.
2. Leer el `README.md` raiz.
3. Editar documentos Markdown en la carpeta correspondiente.
4. Validar que los enlaces y nombres sean claros.
5. Actualizar el README de la carpeta cuando se agregue un archivo.

## Reglas

- No guardar credenciales.
- No agregar archivos temporales personales.
- No mezclar documentos de prueba con documentos oficiales.
- Mantener nombres en espanol y en kebab-case.

## Vista recomendada

Para explicar el proyecto a un companero, abrir en este orden:

2. `02-dominio/modulos`.
