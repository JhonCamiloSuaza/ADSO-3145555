# M05 - Programas de Formacion

## Que significa

Este modulo define la base academica del proyecto: programas, lineas, redes, tipos de formacion, diseno curricular, competencias y RAP. Sin este modulo no se entiende que se va a formar ni con que estructura academica.

## Por que va antes de oferta

Primero se define el programa y su diseno curricular. Despues se crean fichas, proyectos formativos y entregables en el modulo de oferta.

## Alcance inicial

- Lineas y redes.
- Tipo de formacion.
- Linea tecnologica.
- Diseno curricular.
- Competencias.
- Resultados de aprendizaje.

## No incluye

- Fichas concretas.
- Asignacion de aprendices.
- Horarios.

## Entidades principales

| Entidad | Descripcion |
|---------|-------------|
| Programa de formacion | Estructura academica principal |
| Diseno curricular | Organizacion academica del programa |
| Competencia | Capacidad que desarrolla el aprendiz |
| RAP | Resultado de aprendizaje esperado |
| Linea o red | Clasificacion academica del programa |

## Requisitos relacionados

- RF-006: registrar programas, competencias y RAP.

## Servicio propuesto

`academic-management-service`
