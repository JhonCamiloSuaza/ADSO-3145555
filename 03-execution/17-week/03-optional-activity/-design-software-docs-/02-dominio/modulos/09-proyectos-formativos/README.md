# M09 - Proyectos Formativos

## Que significa

Este modulo se encarga del seguimiento de proyectos formativos, notificaciones, alertas e indicadores. Permite saber si la ejecucion academica avanza como se espera.

## Por que va despues de horarios

El seguimiento necesita informacion de proyectos, fichas, actores y horarios. Por eso se documenta despues de la planeacion horaria.

## Alcance inicial

- Seguimiento de proyectos formativos.
- Alertas.
- Notificaciones.
- KPIs de avance o calidad.
- Planes de mejora documentales cuando aplique.

## No incluye

- Creacion del diseno curricular.
- Gestion base de fichas.
- Motor de asignacion de horarios.

## Entidades principales

| Entidad | Descripcion |
|---------|-------------|
| Seguimiento | Registro del avance del proyecto |
| KPI | Indicador de estado o calidad |
| Alerta | Aviso por riesgo, retraso o inconsistencia |
| Notificacion | Comunicacion de un cambio relevante |

## Requisitos relacionados

- RF-011: seguimiento, alertas y KPIs.
