# M10 - Coordinacion y Eventos

## Que significa

Este modulo gestiona eventos academicos y actividades de coordinacion. Sirve para organizar reuniones, jornadas, actividades institucionales o eventos relacionados con formacion y seguimiento.

## Por que va al final

La coordinacion depende de actores, horarios, ambientes, fichas y proyectos. Por eso se ubica despues de los modulos que definen la operacion academica.

## Alcance inicial

- Eventos academicos.
- Agenda de coordinacion.
- Participantes.
- Relacion con horarios, actores o proyectos.

## No incluye

- Gestion completa de horarios.
- Seguimiento de KPIs.
- Administracion de programas o fichas.

## Entidades principales

| Entidad | Descripcion |
|---------|-------------|
| Evento | Actividad programada con objetivo academico |
| Agenda | Organizacion temporal de eventos |
| Participante | Actor vinculado a un evento |
| Coordinacion | Accion de organizacion o articulacion academica |

## Requisitos relacionados

- RF-012: gestionar eventos academicos y coordinacion.

`coordination-service`
