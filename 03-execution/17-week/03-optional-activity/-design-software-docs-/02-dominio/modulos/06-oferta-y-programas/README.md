# M06 - Oferta y Programas

## Que significa

Este modulo convierte la estructura academica en una oferta concreta: fichas, proyectos formativos, entregables y asociacion de aprendices. Es el puente entre el programa definido y la operacion diaria.

## Por que va despues de programas

No se puede crear una ficha o proyecto formativo sin saber a que programa, competencia o diseno curricular pertenece.

## Alcance inicial

- Proyecto formativo.
- Diseno curricular asociado.
- Lista de entregables.
- Fichas.
- Asociacion de aprendices a proyecto formativo.

## No incluye

- Gestion completa de actores.
- Asignacion de horarios.
- Seguimiento detallado de KPIs.

## Entidades principales

| Entidad | Descripcion |
|---------|-------------|
| Ficha | Grupo concreto asociado a un programa |
| Proyecto formativo | Proyecto academico asociado a la ficha |
| Entregable | Evidencia esperada del proyecto |
| Asociacion de aprendiz | Relacion entre aprendiz y proyecto |

## Requisitos relacionados

- RF-007: gestionar proyectos formativos, fichas, entregables y asociacion de aprendices.
