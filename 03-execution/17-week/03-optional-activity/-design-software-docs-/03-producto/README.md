## Relacion con el dominio

El producto se organiza alrededor de los 10 modulos funcionales definidos en `02-dominio/modulos`. La hoja de ruta respeta el mismo orden logico: primero bases institucionales y parametrizacion; despues programas, oferta, actores y horarios; finalmente seguimiento, coordinacion y manuales.
