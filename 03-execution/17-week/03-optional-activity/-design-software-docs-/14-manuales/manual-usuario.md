# Manual de usuario

Este manual explica de forma inicial como un usuario entenderia el sistema por modulos.

## Ruta de uso sugerida

1. Consultar estructura institucional.
2. Revisar catalogos y parametros.
3. Consultar ambientes disponibles.
4. Revisar programas y fichas.
5. Consultar actores academicos.
6. Asignar o revisar horarios.
7. Registrar observaciones o incidencias.
8. Consultar seguimiento y notificaciones.
9. Revisar eventos de coordinacion.

## Modulos

| Modulo | Que hace el usuario |
|--------|---------------------|
| Seguridad y Acceso | Ingresa y opera segun permisos |
| Estructura Institucional | Consulta regionales, centros y ubicaciones |
| Infraestructura | Revisa ambientes e inventario |
| Parametrizacion | Usa catalogos base |
| Programas de Formacion | Consulta programas, competencias y RAP |
| Oferta y Programas | Revisa fichas y proyectos formativos |
| Actores | Consulta instructores, aprendices y directivos |
| Horarios | Revisa asignaciones, observaciones e incidencias |
| Proyectos Formativos | Consulta seguimiento y alertas |
| Coordinacion y Eventos | Revisa eventos academicos |
