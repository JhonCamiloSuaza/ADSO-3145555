# Manual de administrador

Este manual describe responsabilidades administrativas conceptuales. No incluye usuarios reales, credenciales ni configuraciones de plataforma.

## Responsabilidades

- Mantener catalogos base.
- Revisar que la estructura institucional este actualizada.
- Verificar que los documentos del repositorio tengan enlaces correctos.
- Validar que no existan archivos con informacion sensible.
- Promover cambios documentales siguiendo el flujo manual.

## Revisiones frecuentes

| Revision | Frecuencia sugerida |
|----------|---------------------|
| README de carpetas actualizado | Cada cambio documental |
| Matriz de trazabilidad | Cada requisito nuevo |
| Riesgos documentales | Cada hito |
| Catalogo de servicios propuestos | Cada decision de arquitectura |

## Regla

Administrar este repo significa cuidar claridad, trazabilidad y seguridad documental.
