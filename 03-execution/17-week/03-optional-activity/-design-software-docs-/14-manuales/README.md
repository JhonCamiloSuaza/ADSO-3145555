# Manuales

Esta carpeta prepara la explicacion del proyecto para personas que no necesariamente leen arquitectura. Un manual debe traducir modulos, reglas y flujos a instrucciones entendibles.

## Proposito

Los manuales conectan la documentacion tecnica con el uso real esperado. Sirven para explicar que hace cada modulo, que puede hacer un usuario y como una persona nueva entiende el repositorio.

## Documentos

| Documento | Que explica | Estado |
|-----------|-------------|--------|
| [manual-usuario.md](./manual-usuario.md) | Ruta funcional por modulos para usuarios finales | Definido |
| [manual-administrador.md](./manual-administrador.md) | Tareas de administracion documental y funcional | Definido |
| [induccion-tecnica.md](./induccion-tecnica.md) | Lectura recomendada para nuevos integrantes | Definido |

## Regla

Un manual no debe repetir toda la arquitectura. Debe orientar a la persona hacia el documento correcto y explicar el flujo con lenguaje claro.
