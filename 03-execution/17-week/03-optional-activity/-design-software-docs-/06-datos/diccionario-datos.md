# Diccionario de datos

Este diccionario define datos principales del proyecto para que el equipo use nombres y significados consistentes.

| Dato | Significado | Modulo responsable |
|------|-------------|--------------------|
| regional | Agrupacion territorial institucional | M02 |
| centro_formacion | Unidad academica asociada a una regional | M02 |
| ubicacion | Lugar especifico donde ocurre una actividad | M02 |
| ambiente | Espacio usado para formacion | M03 |
| inventario | Recursos asociados a un ambiente | M03 |
| catalogo | Lista controlada de valores | M04 |
| parametro | Configuracion funcional reutilizable | M04 |
| programa_formacion | Programa academico del SENA | M05 |
| competencia | Capacidad definida en el diseno curricular | M05 |
| rap | Resultado de aprendizaje | M05 |
| ficha | Grupo asociado a una oferta formativa | M06 |
| proyecto_formativo | Proyecto academico asociado a ficha y programa | M06 |
| entregable | Evidencia esperada dentro de un proyecto | M06 |
| aprendiz | Persona en formacion | M07 |
| instructor | Persona que orienta formacion | M07 |
| horario | Programacion de actividad academica | M08 |
| incidencia | Situacion que afecta un horario o proceso | M08 |
| seguimiento | Registro de avance de proyecto formativo | M09 |
| kpi | Indicador de estado, avance o calidad | M09 |
| evento | Actividad de coordinacion academica | M10 |

## Regla

Si un documento usa un dato con otro nombre, debe justificarlo o actualizarse para mantener lenguaje comun.
