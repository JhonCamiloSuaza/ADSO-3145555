# Indice de diagramas

Este indice registra los diagramas que el equipo debe crear o mantener. Cada diagrama debe tener fuente editable y exportacion cuando aplique.

| Diagrama | Tipo | Proposito | Estado |
|----------|------|-----------|--------|
| Mapa de modulos funcionales | Dominio | Mostrar los 10 modulos y su orden | Propuesto |
| Flujo de promocion documental | Gobernanza | Explicar ramas y promocion manual | Propuesto |
| Mapa de dependencias de servicios | Arquitectura | Mostrar dependencias entre servicios propuestos | Propuesto |
| Modelo conceptual de datos | Datos | Mostrar entidades principales y relaciones | Propuesto |
| Flujo de asignacion de horarios | Proceso | Explicar como se cruzan ficha, instructor y ambiente | Propuesto |

## Regla

No subir solo imagen final si existe fuente editable. El diagrama debe poder modificarse por el equipo.
