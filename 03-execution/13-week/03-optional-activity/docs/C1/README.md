# C1 — System Context

## ¿Qué es C1?
Muestra el **panorama general del ecosistema tecnológico**: el sistema central, los usuarios que interactúan con él y las dependencias o sistemas externos.

## Audiencia
Gerentes de producto, arquitectos empresariales, desarrolladores y cualquier parte interesada de negocio.

## Contenido de este nivel

| Archivo | Descripción |
|---------|-------------|
| `structure.md` | Árbol completo del contexto del sistema (Simple + Expanded) |
| `variants/simple.md` | Vista simplificada para ejecutivos y stakeholders |
| `variants/expanded.md` | Vista detallada con roles, permisos, protocolos y flujos de interacción |

## Variantes disponibles

- **Simple** → Para presentaciones ejecutivas y reuniones de negocio. Muestra solo el sistema central, actores y sistemas externos a alto nivel.
- **Expanded** → Para arquitectos y desarrolladores. Incluye detalle de cada actor (rol, permisos, canal de acceso, frecuencia) y cada sistema externo (tecnología, protocolo, criticidad).
