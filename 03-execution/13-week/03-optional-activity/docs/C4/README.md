# C4 — Code (Nivel de Implementación)

## Propósito
Mostrar cómo se implementa cada componente a nivel de programación: atributos, constructores, getters, setters y métodos de negocio.

## Audiencia
Exclusivamente desarrolladores de software y arquitectos del equipo.

| Módulo | Archivo | Descripción |

| **Horarios** | `modules/horarios.md` | Entity, IRepository, Repository, IService, Service, Controller, DTO, Utils (ConflictValidator), Exceptions |
| **Security** | `modules/security.md` | Entity (User), Auth endpoints, JWT Utils, Login/Register flows |
| **Inventory** | `modules/inventory.md` | Ambiente, Instructor y Ficha: Entities, Repositories, Services, Controllers, DTOs, Utils (ProccessInventory) |
| **Observation** | `modules/observation.md` | Observation Entity, IRepository, Service (resolve/create logic), Controller, DTOs, Exceptions |
